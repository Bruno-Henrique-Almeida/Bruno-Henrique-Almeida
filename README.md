### Hi 👋

I'm Bruno H. Almeida, a Data Engineer passionate about building scalable and efficient data solutions (and a good mug of coffee ☕).

I have strong knowledge of Python and SQL, experience with SQL and NoSQL databases (PostgreSQL, MongoDB, ClickHouse, Elasticsearch, Redis, Neo4j), and a solid background working with AWS services such as EC2, RDS, SNS, SQS, S3, Lambda, Glue, and Athena.
